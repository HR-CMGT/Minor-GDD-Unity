# Lesson 1.3: UI Layouting & Data Persistence Masterclass

In this lesson, you learn how to build responsive user interfaces (UI) that scale cleanly across any display aspect ratio, and how to persist game data reliably using JSON serialization.

## 🎯 Learning Objectives
1. Build a **responsive Canvas** with proper **Anchors**, **Pivots**, and **Canvas Scaler** configurations.
2. Dynamically bind UI elements (buttons, sliders, text) to C# scripts.
3. Save and load player progression, highscores, and settings via `JsonUtility` and `Application.persistentDataPath`.

## 🖥️ 1. UI Architecture & Canvas Fundamentals

### 3 Canvas Render Modes:
- **Screen Space - Overlay (Default):** Draws UI directly on top of the screen. Ideal for HUD (Health, Score, Minimap).
- **Screen Space - Camera:** Renders UI through a dedicated camera. Required for 3D UI perspective effects or post-processing on UI.
- **World Space:** Places UI physically within the 3D/2D game world (e.g., floating healthbars over enemy heads).

### ⚙️ Golden Settings for the Canvas Scaler:
To prevent UI elements from shifting or shrinking across different resolutions:
1. Select your `Canvas` GameObject.
2. Locate the `Canvas Scaler` component.
3. Set **UI Scale Mode** to: `Scale With Screen Size`.
4. Set **Reference Resolution** to: `1920 x 1080`.
5. Set the **Match** slider to: `0.5 (Width or Height)`.

### ⚓ Anchors & Pivots Explained:
- **Anchors:** Define where the UI element pins relative to parent boundaries when screen dimensions change.
  - Healthbar $\rightarrow$ Anchor `Top-Left`.
  - Pause Menu $\rightarrow$ Anchor `Middle-Center`.
  - Bottom Action Bar $\rightarrow$ Anchor `Bottom-Stretch`.
- **Pivot:** The rotational and scaling origin of the UI element (`0.5, 0.5 = exact center; 0, 0 = bottom-left`).

## 💾 2. Data Persistence: JSON Save System

Avoid using `PlayerPrefs` for full game state storage. `PlayerPrefs` is only meant for simple user preferences (like resolution or volume), not complex inventories or level states.

### Production Save/Load Implementation:

```csharp
using System;
using System.IO;
using UnityEngine;

// Always mark with [Serializable] so Unity can serialize fields to JSON
[Serializable]
public class GameSaveData
{
    public int currentLevel = 1;
    public int highestScore = 0;
    public int totalCoins = 0;
    public float masterVolume = 0.8f;
    public string lastSaveDate;
}

public static class SaveDataService
{
    private static string FilePath => Path.Combine(Application.persistentDataPath, "gamedata_save.json");

    public static void Save(GameSaveData data)
    {
        try
        {
            data.lastSaveDate = DateTime.Now.ToString("yyyy-MM-dd HH:mm:ss");
            string json = JsonUtility.ToJson(data, prettyPrint: true);
            File.WriteAllText(FilePath, json);
            Debug.Log($"[SaveSystem] Saved successfully to: {FilePath}");
        }
        catch (Exception ex)
        {
            Debug.LogError($"[SaveSystem] Save failed: {ex.Message}");
        }
    }

    public static GameSaveData Load()
    {
        if (!File.Exists(FilePath))
        {
            Debug.Log("[SaveSystem] No save file found. Loading defaults.");
            return new GameSaveData();
        }

        try
        {
            string json = File.ReadAllText(FilePath);
            GameSaveData data = JsonUtility.FromJson<GameSaveData>(json);
            Debug.Log($"[SaveSystem] Data loaded. Highscore: {data.highestScore}");
            return data;
        }
        catch (Exception ex)
        {
            Debug.LogError($"[SaveSystem] Load failed: {ex.Message}");
            return new GameSaveData();
        }
    }

    public static void DeleteSave()
    {
        if (File.Exists(FilePath))
        {
            File.Delete(FilePath);
            Debug.Log("[SaveSystem] Save file deleted.");
        }
    }
}
```

## 🎮 3. UI Controller Script (Buttons & Display)

```csharp
using UnityEngine;
using TMPro; // TextMeshPro

public class UIManager : MonoBehaviour
{
    [Header("UI Display")]
    [SerializeField] private TextMeshProUGUI scoreText;
    [SerializeField] private TextMeshProUGUI coinsText;

    private GameSaveData currentData;

    private void Start()
    {
        currentData = SaveDataService.Load();
        RefreshUI();
    }

    public void AddScore(int amount)
    {
        currentData.highestScore += amount;
        RefreshUI();
    }

    public void AddCoin()
    {
        currentData.totalCoins++;
        RefreshUI();
    }

    public void OnClickSaveButton()
    {
        SaveDataService.Save(currentData);
    }

    public void OnClickResetButton()
    {
        SaveDataService.DeleteSave();
        currentData = new GameSaveData();
        RefreshUI();
    }

    private void RefreshUI()
    {
        scoreText.text = $"Highscore: {currentData.highestScore}";
        coinsText.text = $"Coins: {currentData.totalCoins}";
    }
}
```
