### Milestone 1: Mobile Scalable HUD with Safe Area Fitter
Since your game runs on mobile devices with diverse aspect ratios (16:9, 19.5:9, 20:9, 4:3) and hardware cutouts (notches, Dynamic Islands, camera punch holes), all HUD elements must adapt dynamically.

1. **Canvas Scaler Setup:**
   - Create a Canvas: **GameObject -> UI -> Canvas**.
   - Configure the `Canvas Scaler`:
     - **UI Scale Mode:** `Scale With Screen Size`
     - **Reference Resolution:** `1920 x 1080` (Landscape) or `1080 x 1920` (Portrait)
     - **Screen Match Mode:** `Match Width Or Height`
     - **Match:** `1.0` (Match Height) for Landscape mobile games, or `0.0` (Match Width) for Portrait mobile games.
2. **Safe Area Fitter Component:**
   - Create a child GameObject named `SafeAreaPanel` under your Canvas. Set its RectTransform to **Full Stretch** (`Min(0,0)`, `Max(1,1)`).
   - Create and attach the following script `SafeAreaFitter.cs` to `SafeAreaPanel`:
     ```csharp
     using UnityEngine;

     [RequireComponent(typeof(RectTransform))]
     public class SafeAreaFitter : MonoBehaviour
     {
         private RectTransform _rectTransform;

         void Awake()
         {
             _rectTransform = GetComponent<RectTransform>();
             ApplySafeArea();
         }

         void ApplySafeArea()
         {
             Rect safeArea = Screen.safeArea;
             Vector2 anchorMin = safeArea.position;
             Vector2 anchorMax = anchorMin + safeArea.size;

             anchorMin.x /= Screen.width;
             anchorMin.y /= Screen.height;
             anchorMax.x /= Screen.width;
             anchorMax.y /= Screen.height;

             _rectTransform.anchorMin = anchorMin;
             _rectTransform.anchorMax = anchorMax;
         }
     }
     ```
3. **Construct the 4 Mobile HUD Corners (Inside `SafeAreaPanel`):**
   - **Top-Left (Pause Button):** Anchor `(0, 1)`. Ensure minimum touch target is at least **88 x 88 px** (44pt).
   - **Top-Right (Coins / Gems Counter):** TextMeshProUGUI anchored to `(1, 1)`.
   - **Bottom-Left (Virtual Joystick / Movement Zone):** RectTransform touch area anchored to `(0, 0)` with at least 140px diameter.
   - **Bottom-Right (Action / Jump Button):** Button anchored to `(1, 0)` with at least **96 x 96 px** touch target.
4. **Mobile Optimization & Testing:**
   - Uncheck **Raycast Target** on all background images, icons, and non-interactive text labels.
   - Open Unity's **Device Simulator** (**Window -> General -> Device Simulator**).
   - Switch between **Apple iPhone 15 Pro** (Dynamic Island notch), **Apple iPad Air** (4:3 tablet), and a **16:9 phone**. Verify that buttons never get occluded by notches or clipped by screen borders!

### Milestone 2: World Space Overhead Health Bar
- On an Enemy prefab, add a child GameObject named `WorldSpaceHealthBar`.
- Add a `Canvas` component to it and set **Render Mode** to `World Space`.
- Scale the RectTransform down to `(0.01, 0.01, 0.01)` and position it above the enemy's head.
- Add a child UI Slider representing the health bar fill.
- Attach a Billboarding script to prevent the bar from flipping backwards:
  ```csharp
  using UnityEngine;

  public class BillboardUI : MonoBehaviour
  {
      void LateUpdate()
      {
          transform.forward = Camera.main.transform.forward;
      }
  }
  ```

### Milestone 3: Decoupled UI Event Listener
- Create `HealthBarUI.cs` and attach it to your HUD Health Slider:
  ```csharp
  using UnityEngine;
  using UnityEngine.UI;
  using TMPro;

  public class HealthBarUI : MonoBehaviour
  {
      [SerializeField] private Slider healthSlider;
      [SerializeField] private TextMeshProUGUI healthText;
      [SerializeField] private PlayerHealth playerHealth;

      void OnEnable()
      {
          if (playerHealth != null)
          {
              playerHealth.OnHealthChanged += UpdateHUD;
          }
      }

      void OnDisable()
      {
          if (playerHealth != null)
          {
              playerHealth.OnHealthChanged -= UpdateHUD;
          }
      }

      private void UpdateHUD(int current, int max)
      {
          healthSlider.maxValue = max;
          healthSlider.value = current;
          healthText.SetText("HP: {0} / {1}", current, max);
      }
  }
  ```

### Milestone 4: Cross-Platform JSON Persistence Service
- Create `SaveData.cs` to hold your game progress:
  ```csharp
  using System;
  using System.Collections.Generic;

  [Serializable]
  public class SaveData
  {
      public string playerName = "Player";
      public int highscore = 0;
      public int unlockedLevel = 1;
      public List<string> unlockedAbilities = new();
  }
  ```
- Create the static service `SaveSystem.cs`:
  ```csharp
  using System.IO;
  using UnityEngine;

  public static class SaveSystem
  {
      private static string FilePath =>
          Path.Combine(Application.persistentDataPath, "savedata.json");

      public static void Save(SaveData data)
      {
          string json = JsonUtility.ToJson(data, true);
          File.WriteAllText(FilePath, json);
          Debug.Log($"[SaveSystem] Saved to: {FilePath}");
      }

      public static SaveData Load()
      {
          if (!File.Exists(FilePath))
          {
              Debug.LogWarning("[SaveSystem] No save file found. Returning new SaveData.");
              return new SaveData();
          }

          string json = File.ReadAllText(FilePath);
          return JsonUtility.FromJson<SaveData>(json);
      }
  }
  ```
- Test saving when killing an enemy or reaching a checkpoint, and load on `Start()`. Stop and restart Play Mode to verify data persists!

### Unity 6 Golden Rules for Mobile Scalable UI & Persistence:
1. **Canvas Scaler for Mobile:** Set `Scale With Screen Size` (`1920 x 1080` for landscape, `1080 x 1920` for portrait). Use `Match Height = 1.0` in landscape so top/bottom HUD elements never clip.
2. **Safe Area Fitter:** Never anchor interactive buttons directly to Canvas corners on mobile. Place them inside a `SafeAreaPanel` using `Screen.safeArea` to avoid notches and Dynamic Island cutouts.
3. **Touch Ergonomics & Minimum Target:** Buttons must be at least **44 x 44 pt (88 x 88 px at 1080p)** with at least 8-12px padding between buttons to prevent fat-finger mis-clicks.
4. **Raycast Target Optimization:** Uncheck `Raycast Target` on all decorative images, backgrounds, and non-interactive text labels to save mobile CPU cycles during touches.
5. **TextMeshPro:** Always use `TextMeshProUGUI` instead of legacy `Text`. Use `SetText()` instead of string concatenation `+` to eliminate garbage collection.
6. **Decoupled Architecture:** UI components subscribe via `+=` in `OnEnable()` and unsubscribe via `-=` in `OnDisable()`.
7. **JSON vs PlayerPrefs:** Reserve PlayerPrefs strictly for volume/resolution settings. Use `JsonUtility` + `Application.persistentDataPath` for all game state.
8. **Mobile Auto-Save:** Mobile players don't click "Quit Game"; they switch apps or receive phone calls. Implement `void OnApplicationPause(bool pause) { if (pause) SaveSystem.Save(data); }` in your GameManager.
